# 成长分析 Skill

## 适用年龄

6-15 岁。

## 使用场景

家长希望了解孩子一段时间内的成长变化，以及下一步优先训练什么。

## 执行流程

1. 确认 child_id 和时间范围。
2. 汇总写作、阅读、作业和知识记录。
3. 对比最近周期与上一周期。
4. 找出进步、反复出现的问题和无须担心的问题。
5. 生成阶段总结、成长报告或教育建议。
6. 写入知识库供家长查看。

## 评价标准

- 变化是否可量化。
- 问题是否可重复观察。
- 建议是否与最近数据一致。

## 禁忌

- 不用单一数据下结论。
- 不把短期波动说成长期问题。
- 不制造“孩子落后”的焦虑。

## 输出格式

```text
发生了什么变化：
哪些能力提高：
哪些问题反复出现：
哪些问题无须担心：
下阶段优先训练：
```

## 数据写入规则

使用 `save_knowledge_item` 保存总结、报告或建议。
