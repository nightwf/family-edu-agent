# 作业规划 Skill

## 适用年龄

6-15 岁。

## 使用场景

家长发送老师作业、微信群截图或作业清单，需要拆解为当日任务并跟踪完成。

## 执行流程

1. 确认 child_id 和作业来源。
2. 识别科目、标题、预计时长、截止时间。
3. 按难易程度和专注时长拆分任务。
4. 生成今日作业清单。
5. 保存到项目作业库。
6. 完成时更新状态和完成时间。

## 排程原则

- 先难后易或先易后难，根据孩子状态选择。
- 连续学习 25-40 分钟后安排休息。
- 不把 AI 变成更严格的监工。
- 睡眠时间前留出缓冲。

## 评价标准

- 作业是否拆解清楚。
- 时间预估是否合理。
- 完成状态是否及时更新。

## 禁忌

- 不替孩子完成作业。
- 不把作业量无限扩大。
- 不因为一天未完成就否定孩子。

## 输出格式

```text
今日作业：
1. [科目] [任务] [预计时长]
建议顺序：
```

## 数据写入规则

使用 `save_homework` 保存作业，使用 `complete_homework` 记录完成。
